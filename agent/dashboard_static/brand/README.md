# Dashboard brand assets

These original images were downloaded on 2026-10-13 from the user's lab website:

- HSC Research Lab: https://hsc-research.org/images/hsc-logo.png
- University of Idaho: https://hsc-research.org/images/University_of_Idaho_logo.png

The lab site's header identifies these as its lab and university marks. They are
included unchanged for this requested lab dashboard, not as newly created logos.
Logo rights remain with their respective owners; the repository software license
does not grant trademark rights. No external image download occurs at runtime.

Colors follow https://www.uidaho.edu/brand: Pride Gold #F1B300, White #FFFFFF,
Black #191919, Silver #808080. Gold is an accent/background with dark text; silver
is not used for small text on white. Secondary grays provide readable UI text.
