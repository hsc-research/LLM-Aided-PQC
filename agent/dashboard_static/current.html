How to read these results

Measured, estimated, or missing?

Imported synthesis reports are preliminary observations. Routed timing, workload power, and functional verification require their own evidence. Missing values stay unknown.

When is an improvement valid?

Compare the same device, tool settings, constraints, design scope, and verification coverage. A proposal preview is not an accepted design. Candidate values remain Not run until measurements are available.

What does the monitor do?

It reads saved records only. It cannot call an API, edit RTL, launch tools, or approve a candidate. A saved Running status does not prove that a process is still active.
