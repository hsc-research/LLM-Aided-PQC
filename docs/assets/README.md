# README visual assets

- `banner.svg`: existing project banner, recolored to the dashboard's gold,
  charcoal and gray palette. No verification claim is added by its styling.
- `optimization-workflow.svg`: accessible static technical diagram, created for
  the README. Its title/description and the README alt text describe the full flow.
- `optimization-workflow.gif`: 830 × 678, five frames, 9.8 seconds, plays once
  with no loop extension. The highlights are conceptual stages, not recorded tool
  activity. The complete static SVG is shown first; animation is optional.

The figures describe intended evidence gates, not achieved FPGA/ASIC results.
Autonomous ASIC editing and ASIC place-and-route are not implemented. Exploratory
FPGA candidates remain provisional and roll back. Check [project status](../PROJECT_STATUS.md)
and [verification evidence](../VERIFICATION.md) for measured claims.

No real run records, credentials, hostnames or personal paths are included in
these assets. The dashboard's original institutional marks remain in
`agent/dashboard_static/brand/`; their source and usage notes are unchanged.
